# Sistema de Trazabilidad y Digitalización de Insumos Médicos
## Servicio de Farmacia - Clínica Privada Independencia

Trabajo Práctico Integrador para la cátedra de Organización Empresarial (TUPaD - UTN).

### Alcance de la Entrega 4
* **Modelado de Procesos (BPMN):** Flujo de abastecimiento, digitalización de remitos, control de lotes/vencimientos y cotejo contable para pagos a proveedores.
* **Gestión Ágil del Proyecto:** Definición de historias de usuario, criterios de aceptación y tablero Kanban de seguimiento.
* **Indicadores Clave de Desempeño (KPIs):** Métricas para evaluar el impacto del software en los tiempos administrativos y la seguridad de stock.
